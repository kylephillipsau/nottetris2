# nottetris2

A physics-based Tetris game.

## Requirements
Runs on LÖVE 11.5 (ported from LÖVE 0.7.2)

## Installation
1. Install LÖVE 11.5 from https://love2d.org/
2. Run the game with: `love .`

## Compatibility
This version has been updated to work with LÖVE 11.5 and modern systems, including web platforms via love.js.
